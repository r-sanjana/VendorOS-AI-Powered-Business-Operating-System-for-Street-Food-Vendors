# VendorOS

AI-Powered Business Operating System for Street Food Vendors

## Features

- JWT Authentication
- Vendor Management
- Inventory Tracking
- Stock Movement Management
- Sales Analytics
- Expense Tracking
- Dashboard KPIs
- AI Demand Forecasting
- PostgreSQL Database
- Alembic Migrations
- Automated Test Suite

## Tech Stack

Backend:
- FastAPI
- PostgreSQL
- SQLAlchemy
- Alembic
- JWT Authentication
- Pydantic

Testing:
- Pytest
- HTTPX
- AsyncIO
